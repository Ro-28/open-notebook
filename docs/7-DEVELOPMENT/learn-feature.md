# Learn feature (OpenMAIC classrooms)

The **Learn** button on a notebook turns its sources, insights and notes into an
interactive multi-agent classroom (slides, AI teacher, quiz) generated by
[OpenMAIC](https://github.com/THU-MAIC/OpenMAIC), which runs as a sidecar
service next to the Open Notebook API. This is a personal-fork feature.

## Architecture

```
Open Notebook UI (3000)  ──►  Open Notebook API (5055)  ──►  OpenMAIC (3100)
   LearnDialog.tsx              api/routers/learn.py           vendor/openmaic (git submodule)
   iframe <classroom>           api/learning_service.py        POST /api/generate-classroom
                                learning_session (SurrealDB)   GET  /api/generate-classroom/{jobId}
```

1. `POST /api/notebooks/{id}/learn` bundles the notebook into one text corpus
   (`build_material_bundle`: sources' full text + insights + notes, capped by
   `OPENMAIC_MAX_MATERIAL_CHARS`, default 120k) and submits it as `pdfContent`
   to OpenMAIC's classroom job API with the user's `requirement`.
2. A `learning_session` record (migration 25) stores the job id and progress.
   `GET /api/notebooks/{id}/learn` polls OpenMAIC for running jobs.
3. When the job succeeds, `classroom_url` points at
   `${OPENMAIC_PUBLIC_URL}/classroom/{id}`; the dialog embeds it in an iframe.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/learn/status` | Is the sidecar reachable |
| GET | `/api/notebooks/{id}/learn` | List sessions (polls running jobs) |
| POST | `/api/notebooks/{id}/learn` | Create a classroom (202) |
| GET | `/api/learn/{session_id}` | One session, refreshed |
| DELETE | `/api/learn/{session_id}` | Remove the record (classroom stays in OpenMAIC) |

## Running the sidecar

`scripts/app/open-notebook.sh start` (or the macOS app) starts OpenMAIC
automatically: it initialises the submodule build (`pnpm install`, `pnpm build`)
and generates `vendor/openmaic/.env` on first run, preferring an Ollama Cloud
key (`OLLAMA_API_KEY`) and falling back to Cline (`CLINE_API_KEY`), both read
from the environment or `~/.hermes/.env`. Edit that file to change models:

```
OPENAI_API_KEY=...            # any OpenAI-compatible endpoint
OPENAI_BASE_URL=https://ollama.com/v1
OPENAI_MODELS=gpt-oss:120b,...
DEFAULT_MODEL=openai:gpt-oss:120b
ALLOWED_FRAME_ANCESTORS=http://localhost:3000   # baked at build time
```

`ALLOWED_FRAME_ANCESTORS` is read by OpenMAIC's `next.config.ts` **at build
time**; the launcher rebuilds when the UI origin changes.

Open Notebook side env vars: `OPENMAIC_URL` (server-side, default
`http://localhost:3100`), `OPENMAIC_PUBLIC_URL` (browser-facing, defaults to
`OPENMAIC_URL`), `OPENMAIC_ACCESS_CODE` (sent as `x-access-code` if OpenMAIC
has `ACCESS_CODE` set).

## Updating OpenMAIC

```
cd vendor/openmaic && git fetch && git checkout <tag> && cd ../..
git add vendor/openmaic && git commit -m "chore: bump OpenMAIC"
```
The launcher rebuilds when `package.json` changes.

## Roadmap

- Give OpenMAIC's agent a `search_notebook` tool that calls `/api/search` and
  `/api/ask`, so the classroom can pull from the notebook live instead of a
  static bundle.
- Replace the iframe with `@openmaic/renderer` for a native in-app view.
- Per-notebook default model / TTS voice.
